# Cyberion Detection Engineering

## Project Overview
A Detection Engineering and Threat Hunting project focused on identifying,
analyzing, and investigating adversary behavior using real-world security telemetry.

## Objectives
- Develop and validate Sigma detection rules.
- Map detections to MITRE ATT&CK.
- Perform structured threat hunting.
- Investigate security incidents.
- Develop incident response playbooks.
- Identify and document detection gaps.

## Technology Stack
- Python
- Pandas and NumPy
- Jupyter Notebook
- Sigma CLI
- MITRE ATT&CK
- Git and GitHub

## Project Duration
4 Weeks
